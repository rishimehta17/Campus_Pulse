# Campus Pulse

Campus Pulse is an all-in-one student hub for campus events, scholarships, TerpLink discovery, pantry support, and drop-in well-being resources.

## Features

- Scrollable campus events feed
- AI-style relevance ranking
- TerpLink discovery page
- Campus pantry support page
- Scholarship finder with application steps and profile-based matching
- Drop-in well-being page with advisor connection

## Tech Stack

- React
- Vite
- Tailwind CSS CDN

## Run Locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Build

```bash
npm run build
```

## Upload to GitHub

```bash
cd campus-pulse
git init
git add .
git commit -m "Initial commit: Campus Pulse website"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/campus-pulse.git
git push -u origin main
```

Replace `YOUR_USERNAME` with your GitHub username.

## Deploy on GitHub Pages

1. Push the code to GitHub.
2. Go to repository Settings.
3. Go to Pages.
4. Select GitHub Actions or deploy using Vercel/Netlify for easiest React hosting.

Recommended: use Vercel for Vite React apps.
